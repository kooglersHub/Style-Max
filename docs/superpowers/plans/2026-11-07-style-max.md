# Style-Max Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. The user approved implementation in this chat.

**Goal:** Deliver the approved standalone styling studio from photo brief to linked secondhand outfits.
**Architecture:** React/Vite client, FastAPI API, SQLite metadata, private local media, injected AI and marketplace adapters. Optional Diffusers image worker runs separately.
**Tech Stack:** TypeScript, React, Radix UI, Lucide, Python 3.12+, FastAPI, Pydantic, httpx, Pillow, pytest, Vitest.
**Spec:** `docs/superpowers/specs/2026-11-07-style-max-design.md`

## Global Constraints

- Exactly three reference photos and ten initial looks; total shopping-list budget in EUR.
- Persist projects/jobs; protect media by browser session. Never commit runtime data or keys.
- Demo samples are labeled; live failures stay failures. Unknown shipping and sizes stay unknown.
- Work in this checkout and push logical milestones to main as requested by the user.

## Review Focus

- Invalid uploads and cross-session requests must never disclose images.
- Restarted jobs must be recoverable without duplicate generation.
- Unknown shipping and explicit incompatible sizes must not become misleading best deals.
- Remote image fetches must reject private-network hosts and unsafe redirects.
- Partial provider failures must preserve successful offers and explain unavailable sources.
