# Third-party foundations

- React and React DOM — MIT.
- Radix Dialog — MIT; the studio uses its accessible dialog primitives for connections and saved projects.
- Lucide — ISC; interface icons.
- FastAPI, Pydantic, httpx and uvicorn — BSD/MIT licenses as distributed by their maintainers.
- Pillow — HPND.
- `monkrel/kleinanzeigen-api` — MIT; optional unofficial read-only source.
- `Giglium/vinted_scraper` — MIT; optional unofficial read-only source.
- Qwen-Image-Edit-2509 — Apache 2.0 model; model weights are downloaded separately by the GPU worker.
- DM Sans and Instrument Serif — SIL Open Font License; loaded through Google Fonts with local system fallbacks.

UI research included the open-source shadcn dashboard and sidebar blocks. The app uses Radix primitives directly and a custom fashion-studio layout, rather than copying a full analytics template.

Deal-Finder (`kooglersHub/deal-radar`) informed the collector boundary, deduplication and price-state handling. Style-Max is self-contained; no sibling-repository source or credentials are bundled.

Marketplace names belong to their respective owners. Style-Max is not affiliated with those marketplaces. An open-source client's license does not make a private marketplace endpoint an official API or grant platform access. Check upstream terms and your permitted use before enabling community clients.
